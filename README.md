# MiniProject_python_1# Mini-Project #1: From Data Generation to Scientific Analysis

This repository contains my solutions for Mini-Project #1 in *Neuroscience Data Analysis with Python*.

## Repository Structure
- `Q1_neural_spikes.ipynb` – Simulation and analysis of regular, irregular, and bursting neural spike patterns, validation checks, and comparisons across stochastic realizations.
- `Q2_laptop_analysis.ipynb` – Exploratory data analysis of `laptop_price_dataset.csv` (data audit, cleaning, analytical questions, outlier investigation, and analytical report).
- `laptop_price_dataset.csv` – Input dataset for Q2.
- `figures/` – Saved figures generated by both notebooks.
- `requirements.txt` – Required Python packages.
- `AI_USAGE.md` – Documentation of AI assistance and verification.
