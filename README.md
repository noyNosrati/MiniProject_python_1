# Mini-Project #1: From Data Generation to Scientific Analysis

Repository for Mini-Project #1 in *Neuroscience Data Analysis with Python*.

## Repository Contents

- `Q1_neural_spikes.ipynb` — Simulation, statistical analysis, validation, and stochastic realization comparison of regular, irregular, and bursting neural spike trains.
- `Q2_laptop_analysis.ipynb` — Exploratory data analysis, cleaning, visualization, outlier investigation, and scientific report on the laptop price dataset.
- `laptop_price_dataset.csv` — Dataset used in Question 2.
- `figures/` — Exported figures generated by both notebooks.
- `requirements.txt` — Python dependencies required to run the notebooks.
- `AI_USAGE.md` — Documentation of AI tool usage, verification steps, and design decisions.

## How to Run

1. Create and activate a virtual environment (skip this step if you already use an existing Python environment):
   ```bash
   python -m venv .venv
   # On Windows (PowerShell):
   .\.venv\Scripts\Activate.ps1
   # On macOS/Linux:
   # source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `Q1_neural_spikes.ipynb` and `Q2_laptop_analysis.ipynb`, select your Python environment as the kernel, and run all cells from top to bottom.
